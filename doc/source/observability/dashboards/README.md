# Dashboard folder notes

This directory contains the Grafana dashboards used in the challenge.

## Files

- `nodes-overview.json` focuses on cluster node health, CPU, memory, and pod counts.
- `geoapi-overview.json` focuses on the GeoAPI service, its traffic, cache behavior, and runtime health.

## Screenshots

The `screenshots/` folder shows the same dashboards rendered in Grafana so the interview story can include visual evidence.
